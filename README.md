# TTK Label Maker — сайт приложения

Статический лендинг приложения TTK Label Maker: этикетки пищевой продукции и технологические
карты блюд на термопринтере. Android 8.0+, Windows 10/11.

## Состав

```
index.html          страница целиком
assets/css/         стили (тёмно-синяя тема, адаптив)
assets/img/         иконка и скриншоты приложения
download/           APK (PRO, DEMO) и клиент для Windows
.nojekyll           отключает обработку Jekyll на GitHub Pages
```

Сборка не нужна: это чистый HTML/CSS, зависимостей нет.

## Публикация на GitHub Pages

1. Создать публичный репозиторий, например `ttk-label-maker`.
2. Загрузить содержимое этой папки в корень репозитория (файл `index.html` должен лежать в корне,
   а не во вложенном каталоге).
3. Settings → Pages → Source: **Deploy from a branch**, Branch: **main**, папка **/ (root)** → Save.
4. Через 1–2 минуты страница откроется по адресу `https://<логин>.github.io/ttk-label-maker/`.

## Ссылки на файлы

Кнопки скачивания ведут на относительные пути `download/...`, поэтому работают и в корне домена,
и во вложенном каталоге репозитория.

## Примечание

GitHub Pages не предназначен для раздачи крупных файлов. Установщик Windows весит около 12 МБ —
для одного приложения это приемлемо, но при росте числа сборок файлы лучше вынести на файлообменник.
